# Batch QR Scanner

An Android app for scanning many QR codes in a row and copying them as a plain list, one code per line — handy for pasting into Google Forms, spreadsheets or inventory tools.

- Continuous scanning with a live camera view (back or front camera, optional flashlight)
- Only codes inside the visible camera frame are read
- Skips duplicates automatically (can be switched off)
- Remove single codes, copy everything with one tap, or clear the list
- The list is saved on the device, so it survives closing the app
- Works fully offline; nothing leaves the phone
- Light and dark themes

Built with [Capacitor](https://capacitorjs.com/) (web UI in `www/`, native Android shell in `android/`) and the [jsQR](https://github.com/cozmo/jsQR) decoder (Apache-2.0, bundled in `www/vendor/`).

## Get the APK (GitHub Actions)

1. Push this repository to GitHub.
2. Open the **Actions** tab → **Build Android APK**. It runs on every push to `main`; you can also start it with **Run workflow**.
3. When it finishes, open the run and download the **batch-qr-scanner-apk** artifact (a zip containing `app-debug.apk`).
4. Copy the APK to your phone and open it. Android will ask you to allow installs from that source the first time.

To publish a downloadable release, push a tag such as `v1.0.0`; the workflow attaches the APK to a GitHub release.

## Build locally

Requirements: Node.js 20+, JDK 21 and the Android SDK (easiest via Android Studio).

```bash
npm install
npm run build:apk
# APK: android/app/build/outputs/apk/debug/app-debug.apk
```

Or open the `android/` folder in Android Studio after running `npx cap sync android`.

## Project layout

```
www/                 Web app (index.html, styles.css, app.js, vendor/jsQR.js)
android/             Native Android project (generated by Capacitor, committed)
assets/icon-source.png   Master app icon
scripts/generate_icons.py  Rebuilds all launcher icons and splash images from the master icon
capacitor.config.json    App id, name and web directory
.github/workflows/   APK build workflow
```

After changing anything in `www/`, run `npx cap sync android` to copy it into the Android project (the build scripts and the workflow do this for you).

To change the app icon, replace `assets/icon-source.png` (square, transparent corners) and run `pip install pillow && python3 scripts/generate_icons.py`.

## Notes

- The APK produced above is a **debug build** signed with Android's debug key. That is fine for installing on your own devices. For Google Play you would add a release keystore and build `assembleRelease`.
- The app id is `com.batchqr.scanner`. Change it in `capacitor.config.json` before publishing anywhere if you want your own.
- Camera access is requested the first time you tap **Start scanning**.
